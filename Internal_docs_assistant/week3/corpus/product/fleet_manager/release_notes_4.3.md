# Fleet Manager 4.3 — Release Notes (November 2025)

- Battery-aware scheduling now considers dock queue length.
- New traffic rule: one-way aisles.
- REST API v1: added `/missions/bulk`.
- Maximum fleet size remains **50 rovers** per instance.
- Last 4.x feature release. 4.3 receives security fixes until June 30, 2028 (aligned with R2 support).
