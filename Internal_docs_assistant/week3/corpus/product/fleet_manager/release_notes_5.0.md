# Fleet Manager 5.0 — Release Notes (May 2026)

## Highlights
- Support for the **Warehouse Rover R3**. R2 is not supported on 5.x.
- Maximum fleet size raised to **200 rovers** per instance.
- New **REST API v2** with webhooks for mission events.

## Breaking changes
- REST API v1 is **deprecated** and will be **removed on December 31, 2026**.
  Integrations must migrate to v2 before then.
- Single sign-on via SAML is now required for all operator accounts.
