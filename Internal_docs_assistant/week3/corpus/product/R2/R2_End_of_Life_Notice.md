# Warehouse Rover R2 — End-of-Life Notice

Northwind Robotics will retire the Warehouse Rover R2 following the launch of the R3.

| Milestone | Date |
|---|---|
| End of sale | June 30, 2026 |
| Last firmware feature release | December 31, 2026 |
| Security updates end | December 31, 2027 |
| Support and spare parts end | June 30, 2028 |

Existing R2 customers can trade in R2 units for a **20% credit** against R3 purchases
until December 31, 2026. R2 units cannot be managed by Fleet Manager 5.x; customers
running mixed fleets must keep a separate Fleet Manager 4.3 instance for R2 units.
