New Engineer Onboarding

Week 1 checklist

  • Collect your laptop from IT (engineers can request a spec upgrade after 18 months).
  • Set up GlobalConnect VPN (see VPN Setup Guide).
  • Request repository access via the IT portal: Access > New Request.
  • Book the robotics lab safety induction.
  • Read the code review guidelines and the on-call page.

Your onboarding buddy will meet you daily for the first two weeks.
